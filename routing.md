# Routing

Law: use the cheapest model that still does excellent work.

| Work | Model |
|---|---|
| Planning, architecture, final review | Opus 5.5 or Fable 5.1 |
| Building and code edits | Sonnet 5.5 |
| Routine, high-volume work | Haiku 5.5 |
| Independent inspection | Grok |

- The strong model plans and checks. Cheaper models build.
- Escalate one rung after one failed retry.
- Never send secrets or customer data to free or third-party models.
